**Short project description (paste to form):**

NeatRescue is an AI-agent investigation and independent release-gate prototype. It addresses a dangerous failure mode: a plausible code repair can remove the reported symptom while silently breaking legitimate workflows. In a reproducible, synthetic SQLite refund scenario, the broken code produces 4 payments for 3 valid logical refunds. A naive “fix” produces only 1 payment by blocking other valid operations. A model-proposed patch, accepted only after separate verification, produces the correct 3. The agent inspects code context through Entire and runs chosen diagnostics; a version-bound final verifier preserves one durable PASS/FAIL verdict through interrupted checks. The recorded source passes 128 generated adapter cases and all 8 ledger invariants. A direct prompt also fixed this case, so no superiority over direct prompting is claimed. All results are bounded to a four-function synthetic adapter and are not production payment guarantees.
