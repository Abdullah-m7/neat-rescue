NeatRescue is an AI-agent investigation and independent release-gate prototype. It addresses a dangerous failure mode: a plausible code repair can remove the reported symptom while silently breaking legitimate workflows. A model-proposed patch, accepted only after separate verification, produces the correct 3. The agent inspects code context through Entire and runs chosen diagnostics; a version-bound final verifier preserves one durable PASS/FAIL verdict through interrupted checks. All results are bounded to a four-function synthetic adapter and are not production payment guarantees.
